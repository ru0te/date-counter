# date-counter

A small React app that displays and controls a date counter. Built with Create React App and styled using a compact monospace design.

Features
- Simple date display and controls
- Mobile-first responsive layout
- Deploys automatically to GitHub Pages on push to main (GitHub Actions)

Local development
- Install: `npm install`
- Run locally: `npm start` (http://localhost:3000)

Build & deploy
- Build for production: `npm run build`
- CI: workflow builds on push to `main` and deploys to GitHub Pages. Ensure Pages is set to "GitHub Actions" in repository Settings.

Notes
- Fonts, colors, and visual style are preserved. For changes to deployment behavior or workflow adjustments, open an issue or request a change.
